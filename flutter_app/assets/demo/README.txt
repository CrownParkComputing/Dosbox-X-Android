RETRO-DOSBOX HOMEBREW DEMO
==========================

FREEDOS.IMG is a minimal bootable FreeDOS 1.4 environment. It starts
RETRODEM.COM, a small, original 16-bit DOS program supplied solely so that
users and store reviewers can verify the emulator with no external content.

It contains no code, art, audio, data or trademarks from a commercial game,
Microsoft DOS, Microsoft Windows, a PC BIOS, or any other third party product.
The complete source is retro_demo.S. The program is licensed under the MIT
License; see LICENSE.txt.

The FreeDOS kernel and FreeCOM command shell are licensed under GNU GPL v2.
See FREEDOS.txt and GPL-2.0.txt for provenance, licence and source links.

Build from the repository root with:

    tools/build-freedos-demo.sh
