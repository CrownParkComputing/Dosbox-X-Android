# Suggested App Store metadata

## Subtitle

DOS and PC emulator

## Promotional text

Boot the included FreeDOS homebrew demo immediately, then run DOS software you
are legally entitled to use—with touch, keyboard and controller support.

## Description

Retro-DosBox brings a DOS-era PC to iPhone and iPad through the open-source
DOSBox-X emulator.

WORKS THE MOMENT IT OPENS

A minimal FreeDOS 1.4 environment and an original homebrew demo are included.
Boot it with one tap—no account, network connection, external BIOS or download
is required.

COMPLIANCE MODE

A clean install starts in an isolated compliance mode. Only the bundled
FreeDOS demo is visible and your own library is not scanned. The mode is clearly
shown on the main screen and can be changed at any time from Compliance.

BRING SOFTWARE YOU MAY LEGALLY USE

Import DOS folders, ZIP archives, floppy and hard-disk images, and CD images.
Use homebrew, public-domain and open-source software, or copies whose licences
and local law permit your use. Retro-DosBox does not include or help locate
commercial games, Microsoft DOS, Microsoft Windows, proprietary BIOS files or
activation keys.

BUILT FOR PLAY

Use the on-screen keyboard and joystick or a compatible physical controller.
Per-title CPU, video, joystick and advanced DOSBox-X settings help software from
different PC eras run correctly.

OPEN SOURCE

DOSBox-X, the FreeDOS components, this app and the demo are distributed with
their applicable open-source licences and source links. Full details are always
available inside the app under Compliance and About.
